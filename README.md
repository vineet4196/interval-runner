# 🏃 Interval Runner

A simple, mobile-friendly interval running timer designed for runners who want to improve speed, endurance, and consistency.

Run fast, recover, and repeat — without checking your phone every few seconds.

## ✨ Features

- **Customisable intervals:** Set your fast-run and slow/recovery durations.
- **Automatic rep counting:** Counts one completed rep after a full fast and recovery cycle.
- **Target reps:** Set a target or use `0` for unlimited reps.
- **Sound and vibration alerts:** Get notified when an interval changes, where supported by your device and browser.
- **Session history:** Save running sessions in browser storage.
- **Trend analysis:** Review your training history and running consistency.
- **Mobile-friendly design:** Responsive layout for phones, tablets, and desktops.
- **Offline support:** The app can work offline after it has been loaded and its service worker has cached the required files.
- **No account required:** Your running history is stored locally in your browser.

## 🏁 Default Workout

| Activity | Duration |
|---|---:|
| Fast run | 30 seconds |
| Slow/recovery | 90 seconds |

## 📲 How to Use

1. Open the app using your browser.
2. Set the fast-run duration.
3. Set the slow/recovery duration.
4. Optionally set a target number of reps.
5. Tap **Start Run**.
6. Follow the timer and sound or vibration alerts.
7. Review your completed reps and session history.

Use **Reset Session** to reset the current workout and **Test Alarm** to check the alert.

## 📈 Training History and Privacy

- Session history is stored locally in browser storage.
- History normally remains available when you close and reopen the app in the same browser on the same device.
- History is not automatically uploaded to GitHub or shared with other users.
- Clearing browser site data, uninstalling a browser, or using private browsing may remove stored history.
- Use the app's clear-history control to erase saved history when available.

Browser storage is persistent but is not a guaranteed permanent backup. Export important data separately if the app provides an export feature.

## 📱 Add to Home Screen

On Android:

1. Open the published HTTPS website in Chrome.
2. Open the three-dot menu.
3. Select **Add to Home screen** or **Install app**, if available.
4. Launch Interval Runner from your home screen.

## ⚠️ Important Notes

- Keep your phone's media volume at a suitable level.
- Browser autoplay restrictions may require you to interact with the app before sounds can play.
- Background timers and alerts can vary depending on the browser, power-saving settings, and screen-lock behaviour. Test the app before relying on it during a run.
- The timer is a training aid, not a substitute for safe running practices.
